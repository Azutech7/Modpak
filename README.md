# Modpak
Clients do not need to install this modpak (modpack). This is a reference for the server.

Only thing(s) clients need:
- Java 21 JRE
- Minecraft Version 1.21.1
- NeoForge Mod Loader Version 21.1.259
- LWJGL 3 (Lightweight Java Game Library 3)
- [AutoModpack Version 5.0.0-rc.4](https://modrinth.com/mod/automodpack/version/5.0.0-rc.4)
